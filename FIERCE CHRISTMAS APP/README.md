# FIERCE Manifestations App 👑

The official companion journal to the **"A FIERCE Christmas"** album by FIERCE Manifestations featuring Savvy Rayne.

This application is designed to help users transform their holiday season through music, manifestation, and deep journaling.

## Features

- **6 Interactive Journeys**: Corresponds to the tracks on the album (December Diamond, Sleigh All Day, etc.).
- **Digital Journaling**: Save reflections securely to your device.
- **Gratitude Tree**: An interactive "Fiercest Things" tree that grows as you add gratitude items.
- **Music Integration**: Listen to the album or watch the lyric videos directly inside the app.
- **Confetti Celebrations**: Celebrate your wins with visual rewards.
- **Data Backup**: Export your journal entries to keep them safe.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
